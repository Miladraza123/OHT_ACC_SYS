# Icons

Yahan client ke logo se banaye gaye PWA icons rakhein.
`manifest.json` aur `client1-index.html` in naamon ko dhoondte hain:

favicon.ico, favicon-16.png, favicon-32.png, apple-touch-icon.png,
icon-48.png, icon-72.png, icon-96.png, icon-128.png, icon-144.png,
icon-152.png, icon-192.png, icon-384.png, icon-512.png,
icon-maskable-192.png, icon-maskable-512.png

Icons ke baghair bhi app poori tarah chalti hai — sirf PWA install
karne par default icon aata hai.
